# Pulse（MyGO 版）

用 Go + [MyGO](https://github.com/egoist/mygo) 原生 UI 复刻 [jimmgreen/pulse](https://github.com/jimmgreen/pulse) 的核心文件管理器：多标签、多窗格、详细信息 / 平铺 / 图标 / 列表 / 内容视图、地址栏与侧栏、文件操作、暂存盘、标签、文件夹对比、文本差异、搜索和设置。界面由 MyGO 在 GPU 上直接绘制，不使用 WebView，单个 Go 二进制即可运行。

> 范围说明：按本次需求，**不包含快速预览与全盘索引**。原版的 PDF / Office / 视频预览、PulseIndex 服务、AI/MCP 增强包、自动更新和 Windows 默认文件管理器集成未移植；其余核心浏览与整理功能已实现。

## 功能

### 窗口与标签

- 自绘标题栏：应用图标、标签页、新建标签页、设置、信息、最小化 / 最大化 / 关闭。
- 标签页可新建、关闭（含中键关闭）、拖动排序，右键可关闭其他 / 左侧 / 右侧标签页；每个标签页保留自己的布局和窗格位置。可在设置中把标签页放到侧栏纵向排列。
- 启动时可恢复上次的标签页（设置中可关闭）。

### 布局与窗格

- 单栏、左右分屏、上下分屏、三栏、四宫格（`Ctrl+1` … `Ctrl+5`）。
- 每个窗格有独立的路径、历史、视图、排序、分组和筛选；点击窗格中的项目会把命令切换到该窗格。
- 窗格分隔条可拖动；详情面板可显示 / 隐藏并调整比例（`Ctrl+D`）。

### 视图

- **详细信息**：名称、修改日期、类型、大小四列，可点击表头排序，Ctrl/Shift 点击表头可多列排序；拖动列宽、隐藏列；列宽、顺序和隐藏列按文件夹记忆；窄窗格自动只显示名称和大小。
- **平铺 / 图标**：网格视图，图片显示缩略图，其他文件显示彩色类型图标；支持多选和键盘移动。
- **列表 / 内容**：紧凑行和双行信息视图。
- 文件夹优先、斑马纹、彩色扩展名标签、大小比例条、智能日期（今天 / 昨天 / 周几）、按名称 / 日期 / 类型 / 大小分组、按类型筛选。
- 文件夹变化自动刷新（默认开启，可在设置中关闭）。
- 详情面板：缩略图、类型、大小、修改时间、图片尺寸、标签和属性；多选时显示合并摘要。

### 导航与侧栏

- 后退 / 前进 / 上一级、可编辑地址栏（带最近路径自动补全）、面包屑路径、刷新、在此处打开终端。
- 侧栏分区：星标项目、快速访问（主目录、桌面、文档、下载、图片、音乐、视频、快捷方式、回收站）、最近使用、颜色标签、此电脑（磁盘容量条）、网络位置。
- 分区可折叠、拖动排序；快捷方式可添加 / 移除；磁盘、网络位置、标签和回收站可直接浏览。
- 侧栏底部是临时暂存托盘。

### 文件操作

- 复制、移动、删除到回收站、永久删除、重命名、批量重命名（查找替换、前后缀、编号）、新建文件夹、新建文件、创建副本、属性。
- 后台传输并显示进度条，可取消；目标同名时逐项询问替换 / 跳过 / 保留两者，可对全部应用同一选择；文件夹同名时可合并文件夹内容。
- 删除进入内置回收站，可还原、永久删除或清空；操作后可通过提示条撤销。
- 打开文件 / 文件夹、选择打开方式、在系统文件管理器中定位、复制路径 / 名称、在此处打开终端。

### 暂存盘与拖放

- `Ctrl+C` / `Ctrl+X` 把选中项目收进暂存盘（剪切 / 复制两种状态）。
- `Ctrl+V` 把暂存盘内容复制 / 移动到当前窗格；暂存盘可清空、单项移除、两个文件比较。
- 窗格、侧栏暂存盘和系统文件之间支持拖放；拖入窗格默认复制，按住 Shift 移动；拖出到系统使用 MyGO 的文件拖放。

### 标签与对比

- 七个颜色标签（Urgent、Design review、In progress、Pending、Inspiration、Reference、Archive），可新增、改名、删除、改色；侧栏按标签汇总数量。
- 文件夹对比：双栏时比较两侧同名 / 缺失 / 较新 / 不同的项目，并显示统计和差异徽标。
- 文本对比：并排 / 统一视图、仅看差异、忽略空白、忽略大小写、跳转上一处 / 下一处差异。

### 搜索

- 工具栏搜索框按名称过滤当前文件夹，支持中文、全拼和首字母拼音匹配并高亮命中。
- `Ctrl+K` 全局搜索：当前文件夹 / 此电脑 / 所选文件夹三种范围，可包含或不包含子文件夹；搜索框带历史记录自动补全，结果流式加载，可停止、打开、定位、在标签页中查看全部结果。
- `Ctrl+Shift+F` 高级搜索：按类型、修改日期、大小、标签和隐藏项目筛选。
- 不使用全盘索引：搜索按需遍历目录，带深度、数量和取消限制。

### 设置与本地化

- 外观：跟随系统 / 浅色 / 深色、主题色、壁纸图片、界面透明度、背景模糊、列表行高、文字渲染。
- 视图：斑马纹、扩展名颜色、大小条、智能日期、文件夹优先、显示隐藏项目、后台统计文件夹大小、磁盘容量条、删除确认、详情面板。
- 常规：恢复标签页、默认位置、单击打开、开机启动到托盘、开机自动启动。
- 显示语言：跟随系统 / 简体中文 / 繁體中文 / English；日期和数字跟随语言与系统区域。
- 关于与诊断：版本、快捷键列表、恢复默认设置。
- 配置保存在系统配置目录：Windows `%APPDATA%\PulseGo`，macOS `~/Library/Application Support/PulseGo`，Linux `~/.config/PulseGo`。回收站也在这里。

### 桌面集成

- 单实例运行；第二次启动聚焦已有窗口。
- 托盘图标（可选）：关闭窗口时隐藏到托盘，托盘菜单可显示窗口或退出。
- 开机自动启动（Windows 注册表 Run、macOS LaunchAgent、Linux autostart `.desktop`）。
- 使用 MyGO 打包：`go tool mygo build` 生成可执行文件和 Windows 安装包。

## 构建与运行

需要 Go 1.27.3+。

```sh
# 开发运行
go run .

# 普通构建
go build -o pulse.exe .

# MyGO 打包（生成可执行文件和安装包）
go tool mygo build
```

`go tool mygo build` 在 `build/<os>-<arch>/` 输出 `Pulse.exe` 和 `pulse-setup-<version>-amd64.exe`。`go tool mygo dev` 可热重启开发版本。

跨平台交叉编译：

```sh
GOOS=linux GOARCH=amd64 go build ./...
GOOS=darwin GOARCH=arm64 go build ./...
```

## 已知限制

- 快速预览、PDF / Office / 视频 / 压缩包预览未实现（按需求不包含）。
- 全盘索引未实现；搜索按需遍历目录，范围过大时需要缩小范围。
- 壁纸图片与“背景模糊”已生效；透明度、主题色和渐变背景也已生效。
- “文字渲染”设置已保存，但 MyGO 未暴露对应的渲染模式开关。
- 回收站是 Pulse 自己的跨平台回收站（配置目录下），不是各系统的原生回收站；支持还原、永久删除和清空。
- 文件复制 / 剪切使用内置暂存盘；系统文件剪贴板（CF_HDROP / NSPasteboard / X11）未接入，但支持系统文件拖放和文本路径粘贴。
- 未移植：AI / MCP 增强包、自动更新、Windows 默认文件管理器 / 右键菜单集成、PulseIndex 服务。
